
## ?? Standalone Backend API (Groq + ML Model)

To run the API:
1. Add your Groq key to the \.env\ file: \GROQ_API_KEY=gsk_...\`n2. Install dependencies: \pip install -r requirements.txt\`n3. Start the server: \uvicorn backend_api:app --reload\`n4. The API will run on \http://localhost:8000/identify\. Change the Android app's base URL to this address!
